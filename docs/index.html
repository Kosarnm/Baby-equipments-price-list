Edit from the app

To let the app save changes to your list, create a GitHub key once and paste it here. It's stored only in this browser on this phone, and it can only change this one repository.

  1. Open GitHub → New fine-grained token and sign in.
  2. Token name: Baby prices app. Expiration: 90 days.
  3. Repository access: Only select repositories → .
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Tap Generate token, copy it and paste it below.
